Ultrasonic Flow Switch

Product Name: Ultrasonic Flow Switch
Model: WS-06 Series
สถานะ: DRAFT — ไม่ใช่เอกสารอนุมัติ
Document date / ผู้จัดทำ:
หลักฐานและขอบเขต: จัดหัวข้อตาม แบบฟอร์ม F-RD-02 Rev.7 ของ WS-06 (หัวข้อ 1–5 และช่องอนุมัติ) อ้างอิง F-RD-01 WS-06 Rev.12 หน้า 3–5 สำหรับฟังก์ชันและช่วงทำงาน; หน้าเมนูร่างเดิม เป็นตัวอย่าง ไม่ใช่ค่าที่อนุมัติ

ข้อมูลออกแบบเบื้องต้นและตัวเลือกในแบบฟอร์ม

Input Supply / Protection

F-RD-01 ภาคผนวกหน้า 5 ระบุ 220 VAC ±15% 50/60 Hz และ 24 VAC/VDC ±15% เป็นตัวเลือกของซีรีส์; ต้องยืนยันรุ่นย่อยและ schematic

TVS / MOV / Fuse: ค่าและหมายเลขชิ้นส่วนรอยืนยัน ตัวอย่าง Part No. ในแบบฟอร์มไม่ใช่ BOM ที่อนุมัติ

Output / Interface

Relay contact NO / NC / COM ตาม F-RD-01 หน้า 4–5; วัตถุประสงค์หลักคือ Flow Switch

Digital Output protection, contact rating, ขั้วจริง และ Hardware Version: รอยืนยัน; ไม่คัดลอกเมนู 4–20 mA/RS-485 จากแบบฟอร์มทั่วไปมาเป็นคุณสมบัติของ WS-06

1. User Experience Design / Sticker (Draft) — สติกเกอร์ จอ และปุ่ม

F-RD-01 หน้า 3 มีภาพร่าง LCD และการแสดง Flow/ทิศทาง/สถานะ Ultrasonic แต่ไม่ได้ให้แผนผัง segment ที่ยืนยันแล้ว ภาพจอไม่ใช่หลักฐานว่าทุกสัญลักษณ์ทำงานจริงในรุ่น WS-06

ส่วนติดต่อผู้ใช้แบบร่างช่องรอยืนยัน
หน้าทำงานแสดงสถานะการไหลและสถานะ Relay ที่จำเป็นต่อการใช้งานหน้าจอ/ตัวเลข/ไอคอนที่ใช้จริง, segment map
การตั้งค่าStart Delay T1 และ OFF Delay T2จำนวนปุ่ม ชื่อปุ่ม ลำดับกด ค่าเริ่มต้น และรูปแบบแสดงผล
Stickerระบุรุ่น WS-06 Seriesกราฟิก สี ตำแหน่งปุ่ม/ไฟ และไฟล์อนุมัติ

2. Function Design / Flow Chart — ผังการทำงาน

  1. Power ON
    Relay ON ตามคำอธิบายหน้า 3
  2. รอ T1
    จึงเริ่มตรวจการไหล
  3. Flow มีอยู่
    คง Relay ON
  4. Flow หยุด
    รอ T2 ก่อน Relay OFF

หาก Flow กลับมาระหว่าง T2, เงื่อนไขการกลับ ON หลัง OFF, สถานะเมื่อเซนเซอร์ผิดพลาด และพฤติกรรมไฟดับ ยังต้องกำหนด ไม่ถือว่าผังด้านบนเป็น firmware state machine ที่ทดสอบแล้ว

F-RD-01 หน้า 3 และภาคผนวกหน้า 5; อ่าน ผังประกอบเดิม โดยคงสถานะเป็นแบบร่าง

รุ่นท่อช่วง Flow rate (L/h)ช่วง (m³/h)
DN1510–2,5000.01–2.50
DN2020–4,0000.02–4.00
DN2530–6,3000.03–6.30

F-RD-01 ภาคผนวกหน้า 5: ช่วงวัดของแต่ละรุ่น ไม่ใช่ค่า FLOW Active ที่อนุมัติ

3. Connection Terminal / Diagram — รูปแบบการต่อใช้งาน

วงจร/ขั้วหลักฐาน / สถานะ
Supply (AC หรือ AC/DC ตาม variant)F-RD-01 หน้า 4–5 มีภาพร่าง 220 VAC และตัวเลือก 24 VAC/VDC; pin number, L/N/+/− รอตรวจ schematic
Relay NO / NC / COMF-RD-01 หน้า 4–5; หมายเลขขั้ว พิกัดหน้าสัมผัส และ fail-safe state รอยืนยัน
Analog / RS-485 / Pulseเป็นหัวข้อทั่วไปในแบบฟอร์ม F-RD-02; ไม่ระบุเป็น output ของ WS-06 เมื่อ F-RD-01 รุ่นนี้ไม่ยืนยัน

อย่าใส่ pinout ตำแหน่ง terminal 1/2 หรือ RS-485 A/B จากคำแนะนำแม่แบบลงใน Diagram ของ WS-06 โดยไม่มี schematic ยืนยัน

4. Box Size & Mounting — ขนาดกล่องและการติดตั้ง

รายการข้อมูลจาก F-RD-01สิ่งที่ต้องตรวจ

5. Software (User Config) — เมนูตั้งค่า

รายการข้อกำหนด/ตัวอย่างสิ่งที่ยังไม่กำหนด
T1 · Start Delay Time0.5–120 s ตาม F-RD-01 หน้า 3, 5; จ่ายไฟแล้ว Relay ON และเริ่มตรวจการไหลหลังครบ T1ค่าเริ่มต้น, step, เงื่อนไขหากไม่มี Flow ตอนสิ้นสุด T1
T2 · OFF Delay Time0.5–120 s ตาม F-RD-01 หน้า 3, 5; เมื่อ Flow หยุด รอ T2 ก่อน Relay OFFการยกเลิก timer, hysteresis, fault mode
FLOW Active (หากเพิ่ม)หน้าเมนูร่างเดิมใช้ตัวอย่าง DN15: 100 L/h และช่วง 10–2,500 L/hไม่ใช่ข้อกำหนดใน F-RD-01: ค่าเกณฑ์ ช่วงตั้ง เงื่อนไขเปรียบเทียบ และผลต่อ Relay รออนุมัติ
รายการเปิดก่อนอนุมัติ: ยืนยัน schematic/pinout และ contact rating, BOM protection, LCD segment map, รูปแบบปุ่ม, state machine ของ T1/T2, ค่า FLOW Active (หากต้องมี), Drawing มิติ และการทดสอบ IP
